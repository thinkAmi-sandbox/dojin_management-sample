# 技術選定ドキュメント

このディレクトリには、プロジェクトで採用した技術の選定理由と検討過程をまとめています。

## 目的

- 技術選定の透明性確保
- 将来の技術変更時の判断材料提供
- チーム内での技術理解の共有

## 技術選定の基本方針

1. **パフォーマンス優先**: アプリケーションの応答性能を重視
2. **開発効率**: 開発者の生産性とメンテナンス性を考慮
3. **エコシステム**: NestJSとの統合性、コミュニティの活発さを評価
4. **Claude Code親和性**: AIアシスタントが扱いやすい技術を優先

## ドキュメント作成ガイドライン

新しい技術選定ドキュメントを作成する際は、以下の項目を含めてください：

1. **概要**
   - 選定日時
   - 選定技術
   - 決定プロセス参加者

2. **要件定義**
   - 解決したい課題
   - 必須要件と希望要件

3. **比較検討**
   - 検討した選択肢
   - 比較表（機能、性能、コスト等）

4. **選定理由**
   - 決定的な要因
   - トレードオフの説明

5. **実装方針**
   - 導入方法
   - 設定方針

6. **参考情報**
   - 公式ドキュメント
   - 関連記事
