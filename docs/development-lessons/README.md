## 活用方法

### 新機能実装前
1. 類似の技術スタックを使用する場合は該当Phase教訓を確認
2. 特にValidationExceptionFilter関連実装時は必須確認

### 問題発生時
1. エラーメッセージや現象から該当する教訓を検索
2. 解決パターンと参考実装を確認
3. 同じ問題の再発防止策を適用

### 教訓の追加
- 各Phase完了時に新しい教訓ファイルを追加
- ファイル名: `phase-X-Y-lessons.md` 形式
- このREADMEに概要を追記
